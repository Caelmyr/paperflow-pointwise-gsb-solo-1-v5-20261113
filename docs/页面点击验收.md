# 页面点击验收

1. 打开 http://127.0.0.1:8889 ，选择「我的数字档案」。源码首次新环境启动自动建立同名演示集合。
2. 打开「手机拍摄 · 边缘校正练习」，点「检测边缘」，拖动四个绿色圆点，再点「透视校正」。切到「左右对比」检查纸张变直。历史中出现透视处理，恢复原图后可再次练习。
3. 左转、右转，再点自动纠偏。拖动阴影修复强度并执行修复，比较前后。
4. 分别选择灰度、黑白、自适应并「应用色彩模式」，调整阈值和奇数窗口。每次处理都产生历史记录。
5. 点框选区域，在纸张中拖出矩形，点击清理污点，只处理选区。再选区域点提取，输入名称，点击生成的下载链接。裁切后检查图片尺寸，点恢复原图。
6. 打开「从纸张到数字 · 体验文档」，切到文字识别，点击开始识别。图中显示文字框，右侧显示平均置信度、文本。点击一个文字框修改词，或修改全文后保存校订。
7. 顶部搜索输入校订内容回车，应能定位文档页。刷新后校订文本仍在。
8. 勾选所有页，批量执行OCR；打开顶部任务面板观察进度，可取消和重试。取消可能等当前页完成，已处理的页面保留。
9. 拖动缩略图或点上下箭头；复制页，再拆分为新文档。在文档卡片右上勾选两个文档后点合并。删除用复制出的测试页操作。
10. 导出可搜索PDF（所有页OCR需最新）、普通PDF、TXT、图片ZIP、完整归档ZIP。打开PDF搜索PaperFlow及人工校订内容，核对页序。完整归档ZIP含metadata.json与独立二进制文件。
11. 点击更多工具查看真实质量诊断、低置信度复核、工作流、快照、报告和备份。高级滤镜参数由后端模式动态生成。
12. 容器停止再启动后，应仍看到集合、页序、识别及文件；改名复制源码时首次启动重新安装环境，资源不依赖旧位置。

13. 点顶部「▣ JPEG 容量交付」。导入 demo/practice/capacity_delivery 中四张练习图（综合页、照片红字页、色块标志页、纸纹硬页），输入一个宽裕容量（如 3000 KB），保护档位选「均衡」并生成方案。逐页看「最紧指标」与余量，点击页面行核对文字边缘/细彩线/照片渐变三类窗口；候选图应是解码后的实际交付 JPEG，不是未压缩预览。
14. 把容量目标降到方案显示的「底线总量」以下，再生成方案。应显示整批缺口、各保护档位的底线总量，逐页列出不能继续下调的下限质量与采样，确认与下载按钮应不可用；不能出现漏页、缩小尺寸或转灰度的替代方案。
15. 用「调整预算 / 保护后重新比较」提高容量或改用「紧凑」档位。新方案应列出与上一方案的设置差异、逐页质量与字节变化、缺口变化。确认方案后下载；用图片查看器确认每页解码尺寸与源图一致，对比 ZIP 中文件名与清单。
16. 对某页单独设「文字优先」或「细彩线优先」的逐页保护后重新生成，确认该页按新阈值判定。处理该页（例如旋转 0 度）后刷新交付方案页，应提示输入版本已变化、确认与下载失效，必须重新生成。
