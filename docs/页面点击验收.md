# 页面点击验收

1. 打开 http://127.0.0.1:8889 ，选择「我的数字档案」。源码首次新环境启动自动建立同名演示集合。
2. 打开「手机拍摄 · 边缘校正练习」，点「检测边缘」，拖动四个绿色圆点，再点「透视校正」。切到「左右对比」检查纸张变直。历史中出现透视处理，恢复原图后可再次练习。
3. 左转、右转，再点自动纠偏。拖动阴影修复强度并执行修复，比较前后。
4. 分别选择灰度、全局二值、自适应并「应用色彩模式」，调整阈值和奇数窗口。每次处理都产生历史记录。
5. 用「黑白分区」处理混合页：调输出比例、网点单元、网点类型与源稿 DPI，点「生成黑白预览」；在「区域得失」核对文字/线稿/插图/反白各区的保留与损失。对判定不当的区域，在清单中点选归属或框选新增分区，重新预览后点「确认黑白结果」。确认后的页面只含纯黑纯白，预览、提取、下载与 PDF 使用同一份结果；改尺寸后需重新预览核对尺度与可读性。
6. 点框选区域，在纸张中拖出矩形，点击清理污点，只处理选区。再选区域点提取，输入名称，点击生成的下载链接。裁切后检查图片尺寸，点恢复原图。
7. 打开「从纸张到数字 · 体验文档」，切到文字识别，点击开始识别。图中显示文字框，右侧显示平均置信度、文本。点击一个文字框修改词，或修改全文后保存校订。
8. 顶部搜索输入校订内容回车，应能定位文档页。刷新后校订文本仍在。
9. 勾选所有页，批量执行OCR；打开顶部任务面板观察进度，可取消和重试。取消可能等当前页完成，已处理的页面保留。
10. 拖动缩略图或点上下箭头；复制页，再拆分为新文档。在文档卡片右上勾选两个文档后点合并。删除用复制出的测试页操作。
11. 导出可搜索PDF（所有页OCR需最新）、普通PDF、TXT、图片ZIP、完整归档ZIP。打开PDF搜索PaperFlow及人工校订内容，核对页序；黑白页的 PDF 图像应为两色。完整归档ZIP含metadata.json与独立二进制文件。
12. 点击更多工具查看真实质量诊断、低置信度复核、工作流、快照、报告和备份。高级滤镜参数由后端模式动态生成。
13. 容器停止再启动后，应仍看到集合、页序、识别及文件；改名复制源码时首次启动重新安装环境，资源不依赖旧位置。
