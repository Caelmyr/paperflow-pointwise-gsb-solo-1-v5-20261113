JPEG 容量交付练习资料

四种页面分别针对不同损失：
- capacity_check.png：照片渐变 + 细红字 + 浅色表格线 + 正文（整页综合练习，150DPI）
- capacity_check_photo.png：带照片渐变的红字标注页（细彩线在平滑背景上）
- capacity_check_logo.png：色块标志 + 正文（大面积纯色，最先出现色度偏差）
- capacity_check_hard.png：纸纹底 + 密集细红字 + 浅色表格线（最难压低的一页）

使用方法：导入文档后点顶部「▣ JPEG 容量交付」，输入总容量目标（KB），选择保护档位，
生成方案。逐页查看 1:1 解码候选与损失指标；容量不足时会显示缺口与需放宽的保护项。
这些图为项目生成的合成练习资料，不是真实业务数据，也不是验收结果。
